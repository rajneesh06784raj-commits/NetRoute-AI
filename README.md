# 🚀 NetRoute-AI

### AI-Powered Network Routing & Monitoring System

NetRoute-AI is an intelligent network routing and monitoring system that detects network bottlenecks, predicts risks, identifies the best available server, and automatically redirects traffic.

## 🛠️ Tech Stack

- C++ — Network Monitoring Engine
- Java — Backend & REST APIs
- Python — AI/ML & Decision Engine
- React — Web Dashboard

## ✨ Features

- Real-time network monitoring
- AI-based bottleneck detection
- Server health monitoring
- Risk prediction
- Best-server selection
- Automatic traffic redistribution
- Live network dashboard

## 🏗️ Architecture

C++ Monitor → Java Backend → Python AI → React Dashboard
