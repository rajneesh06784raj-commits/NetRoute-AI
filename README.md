## 🎯 Overview

NetRoute-AI is an intelligent network routing and monitoring system that detects network bottlenecks, predicts network risks, identifies the best available server, and automatically redirects traffic for better reliability and performance.

## 🛠️ Tech Stack

| Technology | Role |
|---|---|
| 🔷 C++ | Network Monitoring Engine |
| ☕ Java | Backend & REST APIs |
| 🐍 Python | AI/ML & Decision Engine |
| ⚛️ React | Web Dashboard |

## ✨ Features

- 📡 Real-time network monitoring
- 🤖 AI-based bottleneck detection
- ⚠️ Network risk prediction
- 🖥️ Server health monitoring
- 🧠 Best-server selection
- 🔄 Automatic traffic redistribution
- 📊 Live network dashboard
